# 用户个人常用 BOM reference

选型、替料或精简 BOM 时读取。具体物料由用户提供并保存在项目或其指定资料库，不把某项目的 C 编码写成 skill 通用默认。

## 获取与使用

1. 从 docs/README.md 查找已有常用物料/库存 reference；用户已指定源项目时按授权读取或复制，并保存来源、日期与版本，不重复索要。
2. 没有清单时，明确请用户提供常用 BOM/reference。等待期间可做需求、参数和接口分析；必须继续的新器件标为待与用户清单匹配，不把猜测的“常用料”冻结为用户库存。
3. 先按功能、电气与装配条件筛选，再在合格候选中优先复用。不能为减少 SKU 改动必要的反馈、限流、RC、射频匹配或厂家要求参数。
4. 替换后重新核对准确后缀、引脚、封装和工作条件，并更新真实位号、数量及采购编码。

## 最小资料内容

| 字段 | 用途 |
| --- | --- |
| 厂家、完整型号及后缀、采购编码、封装 | 唯一识别与封装核对 |
| 数值、容差、耐压/功率、介质或频率参数 | 判定可否复用 |
| 状态：偏好/候选/已验证/实物库存及数量日期 | 不把历史选型清单当库存 |
| 适用边界、来源及更新时间 | 避免跨功能或跨项目误用 |

库中存在、Basic/Extended 分类、实时可采购和用户实物库存是不同事实，分别记录核查状态。已有表格字段不齐时只补任务所需内容，不强制重建整份清单。
