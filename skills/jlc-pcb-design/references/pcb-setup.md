# PCB 工程初始化标准

建板后、布局布线前执行；已有工程先读当前值并比较差异，不以模板重置整板。先读 [工艺 reference](jlc-manufacturing.md)选定制造下限，以下为用户长期默认及工程方法，项目明确设置优先。

## 逐项设置顺序

1. **制造输入与单位**：层数、板厚、铜厚、叠层/表面处理、单板/拼板及装配方式；按实际能力设制造下限。按[单位约定](units.md)分别表达，先用一个对象/一项规则核查SDK输入单位，换算留在工具适配处。
2. **板与参考层**：板框/接口方向，铜层功能、相邻参考层、网络及填充方式。配置 GND 内电层或明确的信号层 GND 铺铜；层名不是网络配置。完整制造模板、介质厚度和计算模型一致。
3. **全局规则**：按下表分别设置最低值和绘图默认；包含导线、焊盘、过孔、铺铜/内电层及板边，不能只改布线工具栏。
4. **网络专用规则**：导入网表后识别天线/射频、差分、阻抗、晶振、功率及特殊连接，逐条绑定对象/网络/差分对并建立例外边界，方法见 [关键通路](critical-paths.md)。此时先配置规则；实际走线后再验几何。
5. **原生对象及区域**：按 [固定操作](pcb-operations.md)建立 TP、参考地、天线禁止区域等；尺寸由项目接口/厂家布局确定。
6. **保存核查**：保存后另次读取配置、绑定和代表对象，必要时重开验证。将“目标/原生实值/绑定对象/依据/核查状态”写入项目 setup 记录；未决项明确列出，相关区域暂不按假定值完成布线。

## 默认设置矩阵

| 项目 | 默认/方法 | 核查重点 |
| --- | --- | --- |
| 普通信号绘图线宽 | 10 mil | 密集引出可局部缩窄，电源按电流/温升/压降计算 |
| 制造最小线宽/铜间距 | 按所选层数/铜厚的工艺值；常规 1oz 采用 4 mil | 不能继承到 2oz；不把最小值当全部走线默认 |
| 普通铺铜/内电层至导线与焊盘 | 6 mil，适用满足下限的常规1oz设计 | 这是个人默认；厚铜提高；专用阻抗间距另算并验证优先级 |
| 普通 Via | 钻孔 12 mil / 铜盘 24 mil，密集处铜盘最小 18 mil | 孔和盘分别设置；不改插件孔/NPTH/器件固定脚 |
| 孔边距 | Via 至少 8 mil；插件孔另查至少 18 mil | 只有统一 Hole-to-Hole 时设 8 mil，并另查插件孔；订单更严从严 |
| 同网/异网 Via 中心距 | 同网按孔边距；异网还计铜盘间距 | 按下式计算，不能只查不同网或只看铜盘 |
| 单层焊盘铺铜连接 | 一律直连 | 用户基线，核对默认、命名规则及焊盘局部覆盖 |
| 多层焊盘铺铜连接 | 发散/热焊连接，宽度与间隙按孔盘及装配核定 | 不把过孔和多层插件焊盘混为同类；两者分别核查 |
| 器件焊盘 | 保留核对过的厂家 land pattern，尺寸用mm | 不把所有 Pad 改为同尺寸；铜、阻焊、锡膏分开，圆角不默认批量加 |
| 过孔盖油/盘中孔 | 按所选装配工艺 | 盖油不等于填平，EP 内置孔也需识别 |
| 板边铜距 | 普通锣边至少 8 mil；V割至少 16 mil，保留项目更大值 | 按实际边界类型/局部规则分别落实 |
| TP | 原生测试点，盘径用mm，按探针与板空间确定 | 铜盘/阻焊及测试点报告正确，不默认加锡膏或采购件 |

两孔最小中心距：`max((d1+d2)/2+S孔边, (D1+D2)/2+S铜边)`；第二项用于需铜隔离的不同网。d=孔径，D=铜盘。12 mil 孔、8 mil 孔边要求同网中心距至少 20 mil；不同网在铜间距 4 mil 时，18/18、24/24、18/24 mil 盘分别至少 22、28、25 mil。订单孔边 10 mil 时同网至少 22 mil。

## 初始化完成与后续复查

初始化的完成依据是有效原生规则和网络绑定回读，不是文档有一张参数表。先小量验证再批量设置；不把低精度显示值写回破坏已有阻抗尺寸。绘图、重铺、替料、网络改名/分段或同步后，针对受影响项复核，避免漏掉新网段。

规则改变后重建相关铺铜/内电层并查实际铜；只有最小间距约束不代表生成了目标等间距。制造/绘图/网络覆盖的优先级不猜测，以代表性实际结果验证。验收按 [分级review](review.md)，不把未布线工程的未连接数当作初始化失败或整板通过。
