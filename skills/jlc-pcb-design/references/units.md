# 单位与展示约定

按对象和阅读目的选单位，不按工具返回的单位组织说明。

| 对象 | 默认向协作者展示的单位 |
| --- | --- |
| 走线宽度、差分对内间距、侧地间距及其它铜/孔间距规则 | mil |
| 普通 Via 钻孔、铜盘及其中心距 | mil，保留已选规格，例如12/24 mil |
| 器件本体、引脚间距、封装焊盘尺寸 | mm；跟随原厂尺寸图 |
| TP直径、插件/安装孔尺寸、连接器配合及机械尺寸 | mm |
| 板框、拼板、工艺边、板厚及介质厚度 | mm；铜厚按oz或µm表达 |
| 天线外形、净空和适配铜 | mm；馈线的W/S/G仍用mil |

- 器件封装编码保留原意，例如英制0603；需要区分时说明公制1608或本体1.6×0.8 mm，不将编码当尺寸单位换算。
- 默认展示一个合适单位；只有核对厂家数值、设计规则或换算精度时补充第二单位，不让用户反复换算器件或机械尺寸。
- 工具坐标/参数按当前API契约录入，换算只在调用适配处完成，不影响上述展示。不要为了统一画布单位修改已有真实几何。
- 厂家原始单位留在证据中。确需以整数单位录入制造下限时向安全方向取整，上限不向外放宽；该方法不用于器件推荐焊盘、机械配合尺寸或实测值。
- 0.3 mm与12 mil（0.3048 mm）不是同一准确尺寸；既有尺寸不能因换算、显示取整或回读误差被替换。精度以判断需求为准，不输出无意义小数，也不把测量值取整后宣称通过。
