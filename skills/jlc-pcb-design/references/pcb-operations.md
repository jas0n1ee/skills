# 原生对象与固定操作

对重复操作保持可验证的方法；API 名称、枚举和单位以当前帮助为准，不固定旧 UUID 或内部数值。已有正确对象不为形式统一而重画。

## TP、GND 与网络标签

- PCB 测试焊盘优先使用原生“测试点”类型/工具，指定网络、表面和按探针需要选定的盘径；检查阻焊可接触、锡膏符合装配安排、测试点报告可识别。原生裸铜 TP 不冒充采购器件。机械/电气条件确需独立元件时再选器件。
- 原理图 GND 使用原生 Ground-GND，网络保持 GND，导线接真实连接端；不以普通文字或普通网络标签代替地符号。
- 其它命名网络使用锚定真实导线的原生网络标签，不以普通文本、通用电源符号或不符语义的层次端口代替。一段连续导线避免重复命名来源，改线后回查网表。
- 内层专用地在原生图层中配置“内电层”及 GND；若使用信号层则明确建立 GND 铺铜。图层类型、名称、网络和实际铜分别核查。

## 添加天线净空

1. 根据具体天线厂家参考和实际摆放确定轮廓、馈线/接地/适配铜例外，先识别需要净空的层。不能把任意矩形当作所有天线的通用净空。
2. 在顶层以原生“填充区域”绘制闭合轮廓，将填充类型设为“禁止”；跨层净空将该区域的图层属性设为“多层”，不是改变 PCB 顶层类型。若 SDK 对象名称不同，核对其与 UI 操作的等价性。
3. 在“禁止对象”中选**铺铜、内电层**。导线、元件、填充不一律禁止，以保留有依据的馈线/辐射体/适配铜；需要其它禁项时按具体设计增加，区域图层与禁止对象是两个独立设置。
4. 原生回读确认区域类型、作用层及禁项，重建相关铺铜和内电层，保存后再读。
5. 逐区域逐铜层检查实际 Gerber：允许对象意味着仍须人工/几何核查导线、焊盘、过孔、填充和泪滴。只保留有依据的例外，记录位置、尺寸、网络和下方净空；边界紧邻铜也检查。顶层允许适配铜不等于内层也可留铜。

## 修改铺铜规则

1. 读取默认、命名/网络规则及局部焊盘覆盖，明确当前有效连接方式与安全间距；按 setup 仅改目标字段，保留其余配置。
2. 重建受影响铺铜/内电层，原生保存，再独立回读规则和绑定；实际铜是否连接用导出图形确认，不能只看区域边界重叠。
3. 同时检查连接与间距是否产生变化，受控阻抗通路另按实际 W/S/G 检查。异常先定位规则优先级、派生结果、连接几何或检查器，不先放宽全局间距。

工具无法触发重建且尚未完成时如实记录当前派生结果未更新，不能宣称修改已全部生效。

## 布局与丝印收敛

1. 先放机械接口、天线完整净空与适配铜、关键回流等不可随意压缩的边界，再安排功能簇。空间不足时明确板尺寸与参考设计偏离的取舍，不把缩小净空当作普通排版调整。
2. 分别检查器件本体、焊盘/阻焊、装配操作空间和丝印。对同一贴装面的不同器件，按实际形状、尺寸和旋转计算焊盘交集及边间距，**同网焊盘也纳入**；电气 DRC 可能允许同网铜相连，不能据此放行非预期的焊盘重叠。库里的外框相交不一定是器件碰撞；不要为清理过大的丝印外框而拉长去耦、晶振或射频路径。对手焊还要检查烙铁/镊子接近路径及相邻高件遮挡。
3. 移动元件时同时审查所属连接、地过孔和其它层的走线；移动功能簇后重新读取连接几何，避免用过期线段身份继续编辑自动拆分/合并后的对象。
4. 对确实干涉的非极性轮廓，在核实器件/焊盘间距后局部修整；保留必要器件边界、极性和 pin 1 标记。不要以批量迁移到装配层或隐藏轮廓掩盖布局问题；仅在项目明确选择该显示方式时迁移。隐藏位号不删除元件身份或 BOM 关联。封装子图元变更先验证原生保存后的实例/库结果，再批量处理；线宽统一时统计完整目标集合及例外，不只检查已修改的子集。
5. 交付整体与密集区域的原生截图，分别报告几何、连通和装配检查状态。用户局部微调后，比较前后差异并记录改善原因，将可复用的判断标准提炼为方法；坐标和具体料号留在项目文档。

### 以连接和边界确定对齐

- 先选择每簇的锚点：接口配合边、厂家参考地边/净空，或芯片的目标引脚；再安排其外围。全板不必共用一条中心线，各簇之间保留引出和回流通道。
- 对齐前明确对象：器件本体边、焊盘中心线/铜边、板框或净空边。相同封装可同中心、同方向、等间距排列；不同封装优先对齐参与连接的焊盘，不能拿丝印外框当铜边或强行对齐器件中心。
- 匹配链的串联两端及并联支路的信号端可落在同一通路上，并联器件朝外引地；电容阵列按同网端朝向供电脚、另一端朝回流侧组织。先确认目标焊盘的连接顺序与短回路，再利用行列对齐简化铜形；整齐不能替代去耦距离和回流检查。
- 旋转、镜像或移动功能簇时，把必要的外部铜、净空与地边当作一套相对几何复查。元件朝向正确、矩形尺寸正确，都不能单独证明参考布局仍成立。
- 从人工调整提炼经验时，用稳定器件身份比较前后坐标/角度，量出真正对齐的边界，并结合原生图像解释改善；将“测到的关系”与“推断的摆放意图”分开。不把用户一次具体摆法自动升级为通用最优解。

## 电源铜与引出空间协同布局

先为密集芯片的信号引出、去耦回路和关键参考面预留通道，再选择电源实现。短支路可用走线；同网多焊盘、异形剩余空间可用局部多边形铺铜，避免一条固定宽度的电源线把同层引出全部封住。局部铜不能取消异网间距、焊盘隔离或必要的回流约束。

按功能簇确定电源铜边界和供电入口，设置与地铜的优先关系并重建。检查实际生成铜的连接、最窄颈部、孤岛和被信号/过孔切断的位置；区域轮廓覆盖焊盘不等于有效供电。优先依据电流和压降安排铜截面，不以铺铜面积大推断所有连接都宽。内层电源铜同时核对另一面的高速/射频参考路径，避免为释放顶层空间而割裂参考地。
