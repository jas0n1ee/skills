# 原生对象与固定操作

对重复操作保持可验证的方法；API 名称、枚举和单位以当前帮助为准，不固定旧 UUID 或内部数值。已有正确对象不为形式统一而重画。

## TP、GND 与网络标签

- PCB 测试焊盘优先使用原生“测试点”类型/工具，指定网络、表面和按探针需要选定的盘径；检查阻焊可接触、锡膏符合装配安排、测试点报告可识别。原生裸铜 TP 不冒充采购器件。机械/电气条件确需独立元件时再选器件。
- 原理图 GND 使用原生 Ground-GND，网络保持 GND，导线接真实连接端；不以普通文字或普通网络标签代替地符号。
- 其它命名网络使用锚定真实导线的原生网络标签，不以普通文本、通用电源符号或不符语义的层次端口代替。一段连续导线避免重复命名来源，改线后回查网表。
- 内层专用地在原生图层中配置“内电层”及 GND；若使用信号层则明确建立 GND 铺铜。图层类型、名称、网络和实际铜分别核查。

## 添加天线净空

1. 根据具体天线厂家参考和实际摆放确定轮廓、馈线/接地/适配铜例外，先识别需要净空的层。不能把任意矩形当作所有天线的通用净空。
2. 在顶层以原生“填充区域”绘制闭合轮廓，将填充类型设为“禁止”；跨层净空将该区域的图层属性设为“多层”，不是改变 PCB 顶层类型。若 SDK 对象名称不同，核对其与 UI 操作的等价性。
3. 在“禁止对象”中选**铺铜、内电层**。导线、元件、填充不一律禁止，以保留有依据的馈线/辐射体/适配铜；需要其它禁项时按具体设计增加，区域图层与禁止对象是两个独立设置。
4. 原生回读确认区域类型、作用层及禁项，重建相关铺铜和内电层，保存后再读。
5. 逐区域逐铜层检查实际 Gerber：允许对象意味着仍须人工/几何核查导线、焊盘、过孔、填充和泪滴。只保留有依据的例外，记录位置、尺寸、网络和下方净空；边界紧邻铜也检查。顶层允许适配铜不等于内层也可留铜。

## 修改铺铜规则

1. 读取默认、命名/网络规则及局部焊盘覆盖，明确当前有效连接方式与安全间距；按 setup 仅改目标字段，保留其余配置。
2. 重建受影响铺铜/内电层，原生保存，再独立回读规则和绑定；实际铜是否连接用导出图形确认，不能只看区域边界重叠。
3. 同时检查连接与间距是否产生变化，受控阻抗通路另按实际 W/S/G 检查。异常先定位规则优先级、派生结果、连接几何或检查器，不先放宽全局间距。

工具无法触发重建且尚未完成时如实记录当前派生结果未更新，不能宣称修改已全部生效。
