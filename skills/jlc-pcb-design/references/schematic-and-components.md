# 原理图与选型

以下为可复用的默认表达和选型习惯，已有工程风格与用户明确决定优先。不要为符合默认习惯重排用户已完成的布局。

## 选型证据

- 按功能区记录厂家、完整型号及后缀、采购 C 编码、封装、关键参数、用途、来源、日期与核查状态。先确认选型，再落实原理图/PCB。
- 优先通过已连接的 EDA MCP 核对器件；先读 help/API 文档，不猜测接口、UUID 或料号。库记录不能证明库存、可采购或电气适用性。
- 阻容优先 SMT 基础库并记录查询日期；用户库存与指定器件优先。实际装配服务的分类和费用在下单前复核。
- 尽量减少不同料号与不必要贴片数，但不能随意合并反馈、限流、上电 RC、环路或厂家指定上拉参数；未用通道不照抄全部参考外围。
- 电容核查具体型号在节点电压下的有效容量、耐压、介质和容差，不能只凭标称容量或封装大小判断。功率电感、射频电感与磁珠分别核查电流、饱和、DCR 和频率特性；ESD/TVS 核查工作电压、钳位、结电容、极性和布局。
- 优先采用厂家资料，注明版本及页码/图号。区分库属性、厂家规格、典型曲线、推算和实测结果；保存关键查询证据。
- 替换器件重新核查引脚、封装和电气条件；不匹配时说明差异并记为待核查，不擅自改回旧器件。
- 区分用户指定、代理建议、备选、DNP、已核查及待验证。没有证据不宣称冻结或可投板；电路落实后同步真实位号与数量。

## 原理图表达

- GND 统一使用 Ground-GND 元件，网络名保持 `GND`，不使用普通 GND 网络标签替代。符号可按连线方向旋转，导线接到符号连接端，不得压在 GND 符号主体上；符号避免侵入邻近引脚或标签。此约定用于统一表达与核查；PCB 铺铜实际依据网络归属。
- 图上优先显示读图所需的参数：阻容感显示数值，IC 显示型号，机械开关等可隐藏冗长型号。显示设置与采购属性分离，保留完整 Manufacturer Part、C 编码和封装，不用数值覆盖厂家型号。
- 非 GND 网络使用原生网络标签，标签必须锚定真实导线；GND 按上一条使用地符号。不能用普通文本冒充连接，不能用通用 Power-5V 或双向端口代替任意网络标签；层次端口仅按实际语义使用。
- 同一连续导线只保留必要的一个网络命名来源。给已命名导线叠加标签可能产生重复 Name 属性；隐藏文字不等于删除电气属性。
- 功能分区使用非电气矩形框，将功能标题、对应电路及说明一起框入；边框与文字、器件、导线之间保留间距。
- 块内紧凑、块间留白：同类器件按行列对齐，统一引线长度与标注位置，不为分散布局而把同一功能的器件拆得过远。器件、位号、参数、网络标签、说明和图框明细栏不能重叠；密集引脚用朝外的短引线，标签方向和字号应确保可辨认。
- 功能块内优先直接表达电路关系，例如并联储能电容、输出电感与滤波电容；跨功能块使用网络标签，减少长线和交叉。
- 沿用用户已建立的排版习惯，新增内容匹配现有分框、对齐和文字层级；不因自动整理而重排用户已调整的功能块。
- 避免不相关网络的交叉、共线和端点接触，特别是连接器地脚与配置线、开关节点与反馈/输入电源。确需相连时使用明确分支；反馈标明取样节点。
- 原理图的分散排布不代表 PCB 的物理距离，去耦和反馈布线要求另外记录。用户可以继续调整布局，但交付前仍须完成代理自身的视觉检查。
- 板、原理图和图页按实际功能命名，避免长期使用 Board1、Schematic1、P1 等占位名称；重命名后同步文档入口。
