# 关键通路与特殊连接的方法

天线、差分、阻抗、晶振及特殊连接在导入 PCB 时识别，并在布局前形成最小预期：`端点/逐脚连接 → 覆盖网段 → 物理方向与层 → 约束/例外 → 验证方式`。没有涉及的类型无需加载对应厂家资料。

## 从电路含义建立约束

| 类型 | 布局布线前确定 | 布线后验证 |
| --- | --- | --- |
| 天线/RF | 厂家参考的馈点、接地点、地板/净空、适配铜；区分传输线与辐射体 | 馈线按实际叠层核 W/G/参考地；辐射体按参考几何及板材/环境核查，不套普通50Ω线宽；净空与铜、阻焊分别验 |
| 差分与受控阻抗 | 全部网段/对极性、W/S/G、叠层与相邻参考地、换层与回流、端到端长度预算 | 线宽、对内间距、侧地、实际参考铜及规则覆盖共同核查；焊盘/扇出/过孔局部过渡单独评估 |
| 晶振 | 具体晶体/振荡器类型、厂家布线要求、负载与寄生预算、回流及远离干扰 | 逐支路实际路径、过孔、负载和参考铜；不默认视作差分对，不擅自加50Ω端接或强行等长 |
| 内部贯通/内部短接/局部跨网 | 以厂家引脚表及内部电路建立电气等效与外部走线路径 | 电路连通、EDA连通和布局意图分别验证；不为清飞线增加旁路，不为消报错删必要支路 |

多部件器件检查完整子部件、电源/EP/隐藏脚；去耦用“位号→目标电源脚→就近回流”表达，不仅写“靠近芯片”。默认状态同时检查上电/复位/掉电，不能用固件初始化代替硬件判断。

内部贯通分网的具体核查见 [原理图参考](schematic-and-components.md#esd-器件内部贯通引脚与分网)。局部需要连接不同逻辑网络时，选择支持该连接语义的原生网桥表达，记录涉及网络、允许位置和边界，再验证接地与馈线；网桥范围限定在跨网接合处，同网主通路保持连续并独立检查，不能将整段通路都设为桥接来掩盖连接问题。不全板合网或全局忽略短路。

## 分段差分对与端到端等长检查

- 串联电阻、内部贯通保护器等会把一条实际通路拆成多个网络。先逐脚列出连接器至芯片的 D+/D− 路径，确认器件内部通道；自动生成的 xNet 也要核对节点、端点和极性，防止跨错通道或漏掉末段。
- 分段差分对负责各段的线宽、对内间距、侧铜间距与参考面要求；端到端等长预算绑定到包含完整路径的 xNet 或当前工具支持的等效路径组。不能将各段绝对长度差相加，也不能为满足分段等长而破坏已满足的总长度预算。
- 迁移等长检查前，区分规则数值、规则绑定、检查器启用项和结果显示。只停用不再适用的分段长度检查，保留分段差分对及其阻抗几何规则、端到端长度检查。先查当前版本的原生能力；不预设填 0、留空或隐藏报错等于停用，也不预设 xNet 会自动替代分段检查。
- 若采用自定义 DRC，明确排除项及作用范围，导出配置并记录复用入口；分别核实普通检查、自定义检查和制造导出前检查是否采用同一配置。版本差异和绕行步骤放项目工具记录，不固化为工具永久限制；新增其它差分通道时复核排除范围。
- 保存后独立回读路径、长度、绑定与原有几何规则。首次建立或迁移且检查是否生效存疑时，可临时把容差收紧至小于已知差值，确认出现对应路径错误，再恢复目标并重跑；不改线制造测试错误。记录原生长度统计包含哪些对象，不将 PCB 几何长度直接当含器件内部路径、过孔及封装延迟的时延结果。

## 物理方向检查

连接器及非对称结构先固定观察坐标：公/母、接触面/背面、插入/配合方向、所在板面及原厂图的视角。建立“物理位置—焊盘号—网络”对照，再放置、镜像或旋转；不能仅凭符号脚号和 DRC 判断配合正确。

变换后对照接口图/机械图重新验证；同时检查板框、定位脚、接触长度及走线。原生旋转成功不代表可装配。此方法也用于天线馈点/地端方向，不能把可旋转等同于可任意镜像或缩放。

## 实际结果的证据

- 原生物理叠层、制造标注、计算与订单应一致。工具不能可靠保存时，明确限制与经用户决定的权威制造依据；不宣称只改标注就修好了原生叠层，也不在同一限制下无休止重试。
- 参考面按相邻层的实际 GND 铜判断；正常信号过孔反焊盘不能误判为必须填满的地缺口。换层查回流，局部无法改善时按实际影响分级。
- 制造铜边取填充、描边、焊盘、圆弧、泪滴等图形的并集，计入线宽；不把中心路径、填充轮廓或阻焊边当铜边。连通与有效载流截面也按实际铜判断。
- 天线导入确认单位、比例、线宽、填充、层、网络与馈地端；对照原参考铜或 Gerber 验几何。几何一致不代表本板性能验证通过；不凭截图描线、随意缩放或预设所有天线露铜。
- 陶瓷天线参考布局按“封装焊盘＋外部适配铜”的完整并集核尺寸，区分本体长度、焊盘外边跨度、焊盘中心距和额外延伸长度；同时检查完整地板/净空及馈点方向，不能只补一块铜便宣称复现评估板。
- 对参考图中的每块铜记录端子/网络归属，并区分厂家明确功能与推断；“焊接点”或 NC 不足以证明附近铜没有 RF 作用，内部拓扑未知时保留未知；馈电端宽铜不能替代另一端的延伸铜。先以实际馈点建立局部坐标，再把焊盘、外部铜、净空和地边一起与参考图比较；既量尺寸，也量相对偏移。只禁止铺铜/内电层时，单独核查手工填充及其阻焊开窗；小的定位偏差与缺失整段参考结构按影响分别分级。
- 参考图未独立标注的尺寸标为图形解读，不提升为强制值；分别核查焊接 land、有连续参考地的传输线、地边过渡及调谐/辐射铜。参考地终止后的短段不直接套用原截面的阻抗计算；同制造工艺不代表同端子拓扑，同类资料用于推导核查方法，不用于跨型号复制铜形或匹配值。
- 对多天线比较，记录开关/馈线、未选支路金属、地板、外壳及主机环境，核对匹配位的设计值、DNP 与实装状态。改版保留对照支路，先定义基线和可控变量；实装偏离未排除前不将差异归因于天线型号。测量结论限定为相同条件下的整条通路表现，不冒充独立天线效率。

偏离目标时按 [review](review.md)评估边沿/信号特性、路径长度和局部影响，不以最小间距通过代表阻抗正确，也不把每个局部不均匀截面判为阻塞。
