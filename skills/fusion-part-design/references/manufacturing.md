# 制造与交付检查

仅阅读本次制造流程对应的部分。机器、耗材、材料、工厂、报价渠道、配合与输出目录以用户当前要求和工作区/需求的 `AGENTS.md` 为准；本文件不维护第二份项目配置。

## CNC

- 在应用供应商尺寸规则前确认工厂、渠道和规则版本；已记录的直接沿用。缺项只询问缺失内容，工厂未定仍可建立带待确认标记的概念模型。
- 从工作区公共参考或当前需求资料读取对应渠道的原始证据。若工作区具有 `reference/jlc-cnc-thread-requirements.md`，仅用于其注明的嘉立创渠道；若具有 `reference/cnc-process-requirements.md` 与 `reference/thread-recognition.md`，先核对其归属，现有 AI 零件工作区的这两份资料属于铨洲智造。其他工作区不可仅凭同名文件推定供应商。
- 不把工厂 A 的免费打样识别规则当作工厂 B 或常规报价规则；原始资料互相冲突时保留版本差异，明确本次采用哪项与待核实内容。
- 区分通孔、攻牙底孔、沉孔和沉头孔。按所选螺丝标准核对沉头锥角、直径、深度和锥面下的直孔段；攻牙说明有效牙深、底孔深和通/盲孔。
- 对要求底孔自动识别的供应商，不在实体中建立螺旋牙，按该渠道底孔规则建模并核对识别结果。此规则不自动适用于实体打印螺纹或其他供应商。
- 检查刀具可达性、内角圆角、壁厚、底厚、去料后变形、装夹、表面处理后的配合和装配工具空间。缺少载荷/材料证据时不得宣称强度通过。
- STEP 导出后重新导入核对单位、实体数量、包络、孔型、孔位与关键厚度；二维图、螺纹说明与实体必须使用同一版本。外部 CAD 内核可作独立检验，不能把检验过程描述为原生建模。
- DFM、螺纹识别和加工仿真分别记录已做/未做。只有已有上传授权时才将模型交给供应商；报价请求与下单是不同动作。

## 3D 打印

### 几何与项目文件

- 结合受力方向、层间强度、悬空、桥接、支撑可拆性、首层接触与装配间隙确定打印朝向。配合估值记录为设计建议，按需要使用局部试装件。
- 先导出本次 CAD 的毫米单位网格，再生成打印项目。检查闭合性、退化面、体积、对象数量、包络与原模型一致性；多实体可以是预期结构，不随意合并。
- 3MF 是 ZIP 包，修改包内 XML/JSON 再重新打包，不能向文件末尾追加文字。核对 ZIP 完整性、单位、对象与部件 ID、关系文件、面数、材料分配、板面实例和所有变换。
- 按新模型实际包络重新居中、落板、排盘，检查对象数量与板面边界。不能照抄旧零件偏移；更新预览并去除旧切片结果与无关作者账号信息。
- 如果工作区采用“精简配置拓竹项目 3MF”，读取该工作区确认的配置和样本。已验证的 13 项配置仍依赖本机兼容的官方机器、工艺、耗材预设，不能声称它包含全部切片参数。参数值不在 skill 中另存一份。
- 历史精简配置实验可能只适用于同一模型，不是通用替换器；调用任何旧脚本前检查源网格、对象关联、放置变换、预览和输出路径，避免交付旧零件。

### Bambu Studio 命令行

本工作流历史依据为 macOS Bambu Studio 02.09.01.70（2026-11-09）。新机器、系统或软件版本要实际发现可执行文件并查看 `--help`；以下参数不能代替本机核实。

- 建立本次需求独立的切片工作目录与 `--datadir`，均在工作区约定的外部临时目录内，不依赖或更改用户当前 GUI 配置。
- 使用本机兼容官方预设。`--load-settings` 将机器与工艺 JSON 路径合在一个参数里，以分号分隔；`--load-filaments` 加载耗材 JSON。展开预设必须完整处理 `inherits` 与 `include`，保留机器起止 G-code 和参数数组。
- 壁数、填充、支撑与 brim 按零件和项目约定确定，不从示例外壳推广为通用值。
- 已排好的模型可用 `--arrange 0 --orient 0` 保持布局，`--slice 0` 切片全部板；未排好的模型先设置并核查朝向与板面范围。
- 在历史验证版本中，`--export-3mf` 只传文件名，用 `--outputdir` 指定目录；绝对导出文件名曾导致路径重复。`--export-png` 需要另起调用，不能与切片动作合并。
- 使用参数数组调用 CLI，可避免分号、空格、中文路径在 shell 中被拆分。下面是完成本机预设与路径准备后的调用形状，变量必须取本次任务实际值：

```python
command = [
    str(bambu_executable), "--datadir", str(isolated_datadir),
    "--load-settings", f"{machine_json};{process_json}",
    "--load-filaments", str(filament_json),
    "--arrange", "0", "--orient", "0", "--slice", "0",
    "--outputdir", str(slice_dir),
    "--export-3mf", output_filename,
    str(input_project),
]
```

- 联合检查进程退出码、`result.json` 返回码/错误/警告、实际 3MF 与 G-code；文件存在不能证明切片成功。将当前日志中的警告逐项判断，不因旧项目某个提示最终成功就忽略新错误。
- 重新读取交付 3MF 检查单位、网格、对象数、体积与板面位置。判断支撑可拆性要结合实际 G-code 支撑路径、层高和几何，设置“仅打印平台支撑”本身不能证明所有悬空妥当。
- 导出和切片不等于发送打印授权；测试中不要连接打印机或发送任务。
